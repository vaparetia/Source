○blowbackの仕組み
説明
	ブローバックが必要な武器のみあります。
	毎フレーム必要な関数を実行することでブローバックを実現します。
注意
	BlowBack_RGB6という関数は結局の所使用されていません。
	最終的にモーションで動きを付けた為です。

○clay_bomb_smokeの仕組み
説明
	クレイモア用、指向性のある煙です。
	あたりの計算を最初にやっていしまうので、通常時はあたり計算は行いません。
	壁等にあたると速度を変化させています。こうすることで多少のバラツキが出てリアルになるからです。
	αが０にならない限り処理は続きます。

○mazzleの仕組み
説明
	武器エフェクト、マズルフラッシュ関数の集まりです。
	各武器のマズルフラッシュがそろっています。 煙とフラッシュがセットになっています。

○mazzleflash_sub2の仕組み
説明
	星型をつくるようにしてフラッシュエフェクトを発生させます。
	１フレーム後処理が終了します。

○smokeの仕組み
説明
	指定された場所、範囲から煙を出現させる関数です。
	αが０になるまで処理は続きます。

○smoke2の仕組み
説明
	風の影響を受けるように作られています。
	間を補完する処理も入っています。
	αが０にならない限り処理は続きます。

○sub_mazzleの仕組み
説明
	360度に煙をばらまく関数の本体です。
	特に特殊なことはしていません。

○sub_mazzle_mngの仕組み
説明
	360度に煙をばらまく関数の管理部分です。

○wpeffectの仕組み
説明
	武器エフェクトの初期化をする機能と、管理する機能をもっています。
	武器エフェクトの初期化をした後、管理側を呼出して管理することで
	ブローバックを実現しています。

○mdl_cartridgeの仕組み
説明
	既に確保されているワークに薬夾のポジション、ROT、スピードを設定
    してActで動作させます。
    床にあたることで速度が弱まっていきます。最後には薬夾は動かなくなります。

○cartridgeの仕組み
説明
	薬夾エフェクトマネージャーです。ここから、必要な関数を呼出しています。

○connect_smoke_skoba2の仕組み
説明
	指定されたMatrixにから煙エフェクトを出すものです。
    通常用とデモ用の二種類があります。

○gunsmoke_singleの仕組み
説明
	排薬部分からでる煙エフェクトです。

○gunsmoke_single2の仕組み
説明
	排薬部分からでる煙エフェクトです。
	gunsmoke_singleのバージョン違いです。

○LineSmokeMngの仕組み
説明
	柴田さんの関数を呼び出すラップ関数として作成されましたが、
	使用していません。

○line_boxの仕組み
説明
	コントロール構造体から位置情報をとりだして、その場にラインで立方体を
	表示する関数です。現在は使用されていません。

○p90_mazzleの仕組み
説明
	現在使用されていません。
