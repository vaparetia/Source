○Senserの仕組み
説明
	センサーに触れたかどうかを判定する。
	赤外線は、シナリオから可視化のメッセージ or サーマルゴーグルを装備しない限り表示されない。
	kill命令が親からこないかぎり終了はしない。

○c4_comdlの仕組み
説明
	親からの指示で、αを操作し凍っていくエフェクトを表現しています。
	完全凍結するとαはmaxになります。

○c4_effの仕組み
説明
	一定のタイミングで点滅します。
	冷却されると、タイミングが多少ずれるようになっています。
	ランプが全て消えると終了します。 

○c4_iceの仕組み
説明
	スプレーエフェクト本体です。
	一定のメモリを確保し、その領域のみをしようしてエフェクトを生成しています。
	あたりの計算は親のみにやってしまうことで処理を稼いでいます。

○c4_ice_mngの仕組み
説明
	デモ用にカスタマイズされた、スプレーエフェクト管理マネージャです。

○irs_lampの仕組み
説明
	赤外線装置が作動しているかぎり、点滅します。
	点滅周期は一定です。 破壊されると破壊エフェクトを出し、
	終了します。

○irs_mngの仕組み
説明
	赤外線センサーマネジャーです。
	ここから、どこに配置するか等を決定しています。
	全ての装置が破壊されるとprocを実行して、リスタートが来ない限り終了しません。

○newirsの仕組み
説明
	制御装置本体です。
	指定された場所に装置を配置して、ターゲット変化が起きるまで
    その状態を保ちます。 リスタートするまで終了はしません。

○sensor_lampの仕組み
説明
	センサーの上部についている赤いLEDを制御しています。
	装置が停止状態に陥った時のみ点滅して消えるエフェクトが実行されます。
	それ以外は、ただ光っているだけです。

○TestBoxの仕組み
説明
	これは、練習で作成されたものです。 全く気にしないでください。

○etcの仕組み
説明
	便利関数を集めたソースです。

○test_spriteの仕組み
説明
	スプライトを指定された三次元座標に表示する関数です。
	キャラを生成してから２フレームで自動的に死んでしまいます。 
	おもにデバッグ用に作られたものです。

○sk_printfの仕組み
説明
	L2Dスプライトを使用して文字を表示する為に作成された関数群です。
	中には色を変更する為の関数も存在しますが、すべて文字の事を考え
    て作られているので対象外の使い方をした場合は一切動作を保証しません。
