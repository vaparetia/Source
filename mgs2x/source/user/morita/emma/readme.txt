[仕様]


・手繋ぎイベント

    イベントの仕様
      手繋ぎしながら敵に見つからないように進めなければならない。エマ単独で
    も敵に見つかると危険モードに変わってしまう。
    
      △ボタンをエマの近く(1.5m)で押すことでエマを呼び寄せることができる。
    手を繋ぐまでライデンは動けない。逆に手を繋いでいる時に何らかの形で1.5m
    以上離れてしまうと手を離してしまう。
    
    ダメージ
      銃弾が当たると無敵時間が2秒ほどあります。
      爆発系に対しては1発で死にます。
      パンチキックでは、ダメージはありませんが気絶します。
    
    回復
      手を離してから、時間が経つ(20)としゃがみ体力が回復する。
      エマの体力が１／４以下になると自動的にしゃがみ回復する。
      手を繋ぎながら×ボタンを押すことで手を繋ぎながらでも回復が可能。
    
    その他
      エマに対して、「首締め」「引きずり」なども可能。Ｃ４を背中に付けるこ
    とも可能(爆発させると死にます)。水中に入るときや転ぶとＣ４が背中から外
    れて下に落ちます。


・狙撃イベント

    イベントの仕様
      エマが浮き橋を渡ってＥ脚へ向かう。プレイヤーはエマを攻撃する敵兵及び、
    ガンサイファーを狙撃で倒していく。エマが死ぬとゲームオーバー。エマがＥ
    脚直前まで行くとヴァンプが登場。エマの体力がゼロになる前にヴァンプを倒
    すとクリア。
    
    エマの仕様
      エマが浮き橋を渡ってＥ脚へ向かう。敵から攻撃を受けるとその場にしゃが
    みこみ、敵がいなくなると歩き出す。エマは体力が1/4になるとその場にしゃ
    がみこんで回復しようとする。また、エマの足もとを撃つとその場でしゃがみ
    こむので、しゃがみこんでいる間に回りの敵を排除することも可能である。

[プログラムの内訳]

chara エマ・エメリッヒ[NewEmma]

NPCライブラリをベースに作成。基本モーション（移動やダメージ）、引きず
りモーション、首締めモーションが必要。

全ては、NPCの set_act の値によって思考などが動作する。エマの思考は、現
在の動作にて次の動作を決めるやりかたをとっている。

頻度の高い必要情報は、emma_rcg.cにて行なわれる。これらの情報は、フラグ
によって収集しない場合もあるが、大抵の物は思考ルーチンで必要となる。も
のによっては、思考の中だけで収集する場合(その瞬間しか要らない情報など)
もある。
