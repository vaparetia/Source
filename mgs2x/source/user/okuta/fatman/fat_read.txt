// C4データフォーマット
   C4のデータの持ちかたを
   一次元で一括で扱っていたやりかたから,

   ☆難易度(４レベル)
   ☆パターン（１６パターン）
   ☆インデックス（８個）
   の三段階に分割して管理することにしました。

   pputData[難易度][パターン][インデックス] のような感じです。

   難易度毎に３２パターンの爆弾セットが存在します。

   難易度（ファットマン体力などに依存）->パターン(ランダムで決定)->
   そのパターンにある最大８つのデータの中から検索します。

   例）
   難易度   2
   パターン 5 が選択されている時。
   データは
   pputData[2][5][0〜そのパターンの持つデータ数]の中で決定されます。

   データの３段階の分離はプログラム側で行ないます。	
   GCL側からはフラグで
   『d:FAT_LEVEL_2 | d:FAT_PATTERN_04』のように設定していただければ
   pputData[2][4][0] として扱われます。
   次にまた『d:FAT_LEVEL_2 | d:FAT_PATTERN_04』と出てきたら
   pputData[2][4][1] となります。(同じレベル,同じパラメータ内のデータ数は最大８つまでです)
   すべてのパターンが設置最大数を満たしている必要があります（4個が最大ならデータ数は4〜8で）

// ファットマン立ち位置対応
   ファットマンが爆弾設置する際に目標とするポイントを-aimposという引数で渡せるようにしました。
   -bmposと1対1対応で製作して下さい

// デバック機能
   ファットマンのデバックメニューの
   FATMAN : VIEW-MODE を LEVELにすると
   選択したレベル,パターンが持つ爆弾設置位置を表示します。
   右したの数字は
   LEVEL	: レベル
   PATTERN	: パターン
   PUTNUM	: データ数

   INDEX	: デバック思考時のみインデックス

   それ以下が箱の色の意味です
   
   デバック思考時は
   1コンのL1を押しながら
       左右で数値変化
       上下で変化させたいものの切替え（レベル,パターン）
       L3,R3でインデックス操作して爆弾設置
   です。
   
// ファットマンのGCLパラメータ （5/1 ver）
    -s	
        スピード
    -p
        初期位置
    -over
        C4爆発時のプロシージャ
    -kill	
        ファットマンを倒した時に呼ばれるプロシージャ
    -endknock	
        ファットマンをM9のみで眠らせて倒した時に呼ばれるプロシージャ
    -vox
        ストリーム音声の番号 
        vox.lstに書かれた$t形式。音声名は /mgs2/list/fat_vox.lssに記述されています
    -flagvox
        ストリーム音声再生フラグ
        ストリームの音声を特殊な条件をつけて再生（優先などを想定）したい時に使う予定。現状は０です
    -len_vox
        vox.lstに書かれた$t形式。音声の長さを渡します
    -type (NEW)
        フラグデータ
	上位16ビットは設置情報が入ります
		 4〜11ビットが爆弾セットのパターン番号(0〜31)
		12〜15ビットが爆弾セットの難易度(レベル 0〜3)
		
	下位16ビットは設置タイプを表しファットマンがしゃがんで置くのか立って置くのかなどを判別する

	値の設定はw20c_fat.gclのdefineを参照
    -nmtrap
	トラップ名
	レーダー表示用トラップの名前を入れて下さい
    -bmpos
        設置位置データ群 
	C4を置く場所です
    -aimpos (NEW)
        設置時のファットマン立ち位置データ群 
	C4を置く際のファットマンが移動する目標地点です
    -rot
	設置回転情報データ群
	C4の向きのデータ列です
    -cont
        対ビハインド用タイプフラグ
        対ビハインド用のルーチンに使用するバウンドボックスデータ(-hakoで渡す)に対応したフラグです。
        プログラム側でいろいろやると思います
    -hako
        対ビハインド用バウンドボックスデータ
        対ビハインド用のルーチンに使用するバウンドボックスデータ
        プログラム側でいろいろやると思います

// 攻略法
ダメージは頭部狙撃かボム系爆発のみ与える事ができる

転倒させる->倒れているファットマンの頭狙撃->起き上がってくらくらしているところを更に頭狙撃
スタングレネードでくらくらしているところを頭狙撃

転倒させる方法	
    走行中のファットマンのブラストスーツ部分に連続で銃撃を与える(移動していない時はブラストスーツ部分はノーダメ)
    ローラーブレードを狙撃する
    ボム系爆発でふっとばす
    殴り,蹴り
