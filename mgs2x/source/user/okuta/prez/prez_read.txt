// 大統領仕様


反応部分

大統領の反応はニキータ発見時のニキータの存在するエリアと大統領の存在するエリアからテーブルを参照して
逃げる地点を選びだし、その地点に到着したら行動を起こす形になっています

-conf // 逃げポイント座標データ (最大64)
	逃げポイント座標を設定

-area // 逃げポイントインデックス( 8 * 8 )
	ニキータの存在するエリア × 大統領の存在するエリア の固定数( 8 * 8 の固定)
	逃げポイント座標(-conf)の何番目の位置に逃げるかをインデックスで渡します(0〜63)
		ニキータがエリア１にいて、大統領がエリア５にいる時,
		[1][5]の内容が 7 なら  -conf の ８番目のエリアに逃げます。
-iplayback // 反応インデックス( 8 * 8 )
	ニキータの存在するエリア × 大統領の存在するエリア の固定数( 8 * 8 の固定)
	大統領が逃げポイントに到着したら起こす行動を記述します。
	反応のデファインはcommand.defにあります
		PREZ_REACT_EVADE_B なら	背中張りつき、
		PREZ_REACT_EVADE_U なら サマーソルトを出します
