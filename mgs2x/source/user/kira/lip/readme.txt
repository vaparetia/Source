

リップシンクドライバおよび、
マルチウェイトモデル用顔アニメーションモジュールの説明




command.def に以下のように記述することで、ドライバと顔アニメモジュールの双方が
使用可能となります。

---(ここから)-------------------------------------------------------------
// ドライバ
command リップシンクドライバ[GM_StreamLipDriverInit]

// 顔アニメモジュール
chara 顔アニメ[NewFaceMotionSet] $s:name \
      -chara $s:キャラ名 \
      -a $d:顔アニメモーションパーツ群

mesg 顔アニメ $s:名前 表情設定[0] $s:モーション名 $w:レート $w:補間時間
mesg 顔アニメ $s:名前 表情ニュートラル[1] $w:補間時間
mesg 顔アニメ $s:名前 口パク強度[2] $w:強度
mesg 顔アニメ $s:名前 強制目パチ[3] $w:目パチ回数
mesg 顔アニメ $s:名前 自動目パチ禁止[4]
mesg 顔アニメ $s:名前 自動目パチ許可[5]
---(ここまで)-------------------------------------------------------------

リップシンクドライバを使用したいステージのソースにおいて、

	command リップシンクドライバ

を実行することにより、リップシンクドライバが組み込まれます。
顔アニメモジュールを使用する際、必ず必要になるので忘れないようにしてください。

なお、リップシンクドライバはまだ暫定版であるため、話者情報が含まれていません。
現状ではリップシンク情報をもつストリーミングデータを再生すると、顔アニメ
モジュールを組み込んだ全てのモデルが口パク動作をしてしまいます。


マルチウェイトモデルに対し、顔アニメモジュールを使用する場合、
例えばモデルが

	chara マルチウェイトキャラ マルチ \
		-name d:PLAYER \
		-model sna_def_mh

などと定義されている場合、

	resource lip {
		 snake:
			$s:{
				sna_face_speech_a,  // 「あ」の形
				sna_face_speech_i,  // 「い」の形
				sna_face_speech_u,  // 「う」の形
				sna_face_speech_e,  // 「え」の形
				sna_face_speech_o,  // 「お」の形
				sna_face_speech_N,  // 「ん」の形
				sna_face_speech_v,  // 英語の 'v' の形
				sna_face_close_eyes // 目閉じ状態
			}
	};	
	chara 顔アニメ face -chara d:PLAYER -a [lip:snake]

とすることで、顔アニメーションに必要な、各種の口形状および目閉じのモーションを
定義することができます。リソースとして記述するモーションデータの順序は、上記の
通りにしてください。

顔アニメモジュールを組み込んだ後は、以下のアクションを顔に対して起こすことが
できます。

◎表情の設定

	mesg 顔アニメ $s:名前 表情設定[0] $s:モーション名 $w:レート $w:補間時間

	例) mesg 顔アニメ face 表情設定 sna_face_anger 500 150

	.rmt で作成された表情のモーションに、顔を変化させます。

	「レート」というのは表情変更完了後のモーションの強さで、0〜1000の間で
	指定します。0 は完全なニュートラル、1000 は.rmt で指定された形状
	そのものです。

	「補間時間」は、表情の変化が終了するまでの時間で、1/300秒単位で指定
	します。

	既に他の表情が設定されている場合は、ニュートラル状態を経由せず、
	直接新しい表情に移行します。



◎表情の解除

	mesg 顔アニメ $s:名前 表情ニュートラル[1] $w:補間時間

	例) mesg 顔アニメ face 表情ニュートラル 150

	表情をニュートラル状態にします。補間時間は「表情設定」と同様、
	1/300秒で指定します。



◎リップアニメーション強度の指定

	mesg 顔アニメ $s:名前 口パク強度[2] $w:強度

	例) mesg 顔アニメ face 口パク強度 500

	顔アニメーションモジュールが組み込まれている場合、リップシンク情報が
	含まれた音声ストリーミングデータを再生すると、自動的にリップアニメー
	ションを行いますが、その際の動きの大きさを指定します。

	強度は 0 〜 1000 の間で指定し、0だと全く動かず、1000 であれば最大の
	動きになります。



◎強制目パチ発動	

	mesg 顔アニメ $s:名前 強制目パチ[3] $w:目パチ回数

	例) mesg 顔アニメ face 強制目パチ 3

	演出上強制的に目パチアニメーションを行わせたい場合、このメッセージを
	使用します。

	指定された回数分、連続して目パチを行います。


◎自動目パチの禁止

	mesg 顔アニメ $s:名前 自動目パチ禁止[4]

	例) mesg 顔アニメ face 自動目パチ禁止

	顔アニメモジュールが組み込まれたデフォルトの状態では、「自動目パチ」
	機能が許可状態になっており、約4秒前後おきに、自動的にキャラクターを
	まばたきさせます。

	演出上この状態ではまずい場合、このメッセージを使用して自動目パチ機能
	を OFF にする必要があります。

	禁止状態においても、「強制目パチ」を使用することにより、任意箇所での
	目パチを発動することができます。

	

◎自動目パチの許可

	mesg 顔アニメ $s:名前 自動目パチ許可[5]

	例) mesg 顔アニメ face 自動目パチ許可

	「自動目パチ」機能を、許可状態にします。


以上。
