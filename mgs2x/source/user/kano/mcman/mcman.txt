メモリーカードシーケンスマネージャー(MCMan)の使い方


MCManの起動
	NewMCMan()を呼び出す。

		#include "mcman.h"

		NewMCMan();


MCManの使い方
	メモリーカードチェック中画面
		MCManChecked()を確認し、ファイル選択画面に移行。

	ファイル情報取得
		オートチェック機構によって、メモリーカードの情報が取り出される。
		ファイルの情報は、GetPhotoInfoStart(GetGameInfoStart)を使って、
		ファイル情報取得モードに入ることで読み出される。
		チェックできるサイズを可能な限り大きくするために、指定したポートの
		ファイル情報しか取得出来ないので、ファイル選択画面では、
		ポートの指定 --> ファイル情報取得 --> ファイル指定画面の順で
		状態遷移するようにする。

	ファイルの選択画面
		MCManChecked()を各フレーム一回実行し、メモリーカードのチェックが終了しているかどうか
		確認する。もしメモリーカードのチェックが終了していれば、MCManIsMCChangedを呼び出し、
		メモリーカードが変更されたかどうか確認する。
		変更されていれば、"ポートの指定画面"まで戻る。

        2001/6/25 Ken Kano 修正

   		-- MCManCheckingOrChecked()を各フレーム一回実行し、メモリーカードのチェックが
		-- 行われているかどうかチェックする。
		-- 行われていれば、メモリーカードチェック中画面に移行。

	セーブ/ロード画面
		SavePhotoStart(LoadPhotoStart,SaveGameStart,LoadGameStart)を呼び出す。
		返り値が1の場合、正常にSave/Loadのモードに入っている。
		0が返った場合、マネージャー側がAutoCheckのモードに入っているので、
		メモリーカードチェック中画面に移行。

		SavePhotoStart(LoadPhotoStart,SaveGameStart,LoadGameStart)の結果は、
		MCManGetResult()にて確認する。
		0はSave/Load中、1は正常終了、-1はエラー終了。
		エラー終了した場合は、MCManCheckingOrChecked()を確認し、
		メモリーカードのチェックが行われたかどうかを確認し、
		メモリーカードチェック中画面に移行。

		フォーマット
			セーブの際にフォーマットのモードに入ることがあるが、
			フォーマット中の検出は、MCManFormating()で検出し表示に反映する。

	メモリーカードアイコンをテクスチャから作成する場合
	メモリーカードアイコンからテクスチャを取り出す場合
		MCManは、デフォルトのメモリーカードアイコン形式のために専用領域を
		確保しています。MCMan_PhotoIconEncodeを呼び出すと、その専用領域に
		デフォルトのモデル情報と引数として指定したテクスチャを、アイコン形式に
		直して展開します。SavePhotoStart,SaveGameStartでこのアイコンをセーブしたい
		場合には、icondataにNULLを指定します。
		また、LoadPhotoIconStartを使いますと、写真データと一緒にセーブされている
		アイコンデータを取り出すことが出来ます。アイコンは、LoadPhotoIconStartの
		icondataで指定された領域、もしくは専用領域にロードされます。専用領域に
		ロードを行った場合は、ロード後にMCMan_PhotoIconDecodeでテクスチャのみを
		取り出すことができます。
		アイコンのテクスチャは、MCMan_PhotoIconEncode,MCMan_PhotoIconDecodeを
		使う場合、16BitColorで48x32と規定しています。このサイズは、mcman.hの
		ICON_TEX_WIDTH,ICON_TEX_HEIGHTを変えることで変更が可能です。


MCManを使ったファイル管理画面のシーケンス

                 スタート
                     |
                     |
                     | <---------------------------
                     V                            |
                 メモリーカードチェック画面       |
                     |                            | メモリーカード
             ------> |                            | オートチェック
ポートの変更 |       V                            |
             |   ファイル情報取得中画面 ----------|
             |       |                            |
             |       |                            |
             |       V                            |
             --- ファイル選択画面 ----------------|
                     |                            |
                     |                            |
                     V                            |
                 セーブ／ロード -------------------
                   確認画面
                     |
                     |
                     V
                    実行
                     |
                     |
                     V
                   エンド


セーブされるファイル
	BISLPM-xxxxxrrrGyyy
		ディレクトリ名には、前半にSONYからもらったプロダクトコードを用いる。
		後半は、<file ver.>G(ame)<num>という形式をつけることにする。

		icon.sys ..........	アイコンに関する情報
							PS2のメモリーカードプラウザが使用するために
							必ず要る。

		BISLPM-xxxxxrrrGyyy
					.......	BISLPM-xxxxxrrrGyyyというディレクトリには、必ず同じ名前の
							ファイルを入れなければならない。
							ただ、このファイルがデータファイルである必要はないので、
							アイコン表示データを入れようかと思う。

		Dxxxxxxxxxxxxxxx .. ゲームのデータ。
							D(ata)<付加情報コード(30文字)>

	BISLPM-xxxxxrrrPyyy
		ディレクトリ名には、前半にSONYからもらったプロダクトコードを用いる。
		後半は、<file ver.>P(hoto)<num>という形式をつけることにする。

		icon.sys ..........	アイコンに関する情報
							PS2のメモリーカードプラウザが使用するために
							必ず要る。

		BISLPM-xxxxxrrrPyyy
					.......	BISLPM-xxxxxrrrPyyyというディレクトリには、必ず同じ名前の
							ファイルを入れなければならない。
							ただ、このファイルがデータファイルである必要はないので、
							アイコン表示データを入れようかと思う。

		Dxxxxxxxxxxxxxxx .. 写真データ。付加情報は、コード化してファイル名に入れる。
							D(ata)<付加情報コード(30文字)>
