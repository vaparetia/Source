	■環境設定方法
		１）次のディレクトリをマウントする。
			
			nagato:/exports/mj001b 
		    nagato:/exports/mj001data 

		２）以下にパスを通す。

			/usr/local/sce/ee/gcc/bin 
	        /usr/local/sce/iop/gcc/bin 
	        /usr/local/sce/bin
			/u/develop/mj001b/tools/bin/linux

		３）環境変数を設定する。

			setenv CVSROOT /u/develop/mj001b/cvsroot	//ＭＧＳ２開発ＣＶＳのルート
		    setenv CVSEDITOR mule 			//ＣＶＳでコメントを書くエディター
		    setenv DSNETM psjw002 			//自分のＴ１００００
												(ホントにpsjw002と書くと、
													園山のマシンになってしまいます。）

		４）ＰＳ２ライブラリをローカルにコピー

            cd /usr/local/develop/
		    tar zxvf /u/develop/mj001b/develop/scelib/ver213hdd.tar.gz //その時点での最新
		    cd /usr/local
			rm sce
			ln -s /usr/local/develop/ver213hdd/sce sce				   //その時点での最新

		５）Ｔ１００００のアップデート

			※必ず左下のディップスイッチがTOOL側になっていることを確認してください。

			dsflash /u/develop/mj001b/develop/scelib/ver213hdd/t10000-rel2132hdd.bin //その時点での最新
			を実行。

		   	dsresetが正常に動けば完了です。

		６）ＭＧＳ２開発環境の構築

			cd	/usr/local/develop
			cvs checkout mgs2

	■開発の流れ

		１）ステージ構築
				mgs2/list 以下で、				make all
				特定のステージだけのときは		make 'ステージ名'
				デモ							make demo
				音声							make vox sound
				モーションヘッダ作成			make mh

				詳細は、mgs2/list/readme.txt

		２）シナリオＭＡＫＥ
				mgs2/scn 以下で、				make
				特定のステージだけのときは		setenv MGS2STAGE 'ステージ名' の後、make
				リンクするプログラムを決定する	make stage	（mgs2/source からでも可能）
				
				mgs2/source から				make scn 

		３）プログラムコンパイル
				mgs2/source 以下で
				全部							make
				あるディレクトリ以下			make 'ディレクトリ名'
				リンクのみ						make link

		４）実行
				mgs2/source, mgs2/scn から		make run
