□MGS2 system overview

MGS2システムは以下のような階層にわかれている。

|---------------------------------------------------------|
|                        USER                             |
|---------------------------------------------------------|
|                        GAME                             |
|---------------------------------------------------------|
|   FS, GCL, HZX, MT, UTL              |        DG        |
|--------------------------------------------             |
|                         GV                 |            |
|---------------------------------------------------------|

各システムの受け持ちは以下の通り。

-----  system ------

・GV

メモリ管理
ACTOR管理
メッセージ処理
PAD等資源管理
文字列ID等システム共用ユーティリティ

・DG

表示関係すべて
オブジェクト／プリミティブ管理

・FS

ファイル管理(CD/開発環境をシームレスに扱う)
ステージデータロード
ストリーミング

・GCL

GCLパーサー
GCL変数管理

・HZX

あたりデータ管理／検索

・MT

モーションデータ管理／展開

・UTL

いろいろユーティリティライブラリ

----- game ------

・GAME

MGS2のタイトルに特化した管理／ユーティリティ関数群。
よりユーザーから扱いやすいような高レベル関数を提供する。
各systemの関数を使用し、OBJECT, CONTROL, MAPなどの概念を構築。

----- user ------

・ゲーム中の各キャラクタとして、担当者が作成。
