Build the game in VTA_Develop.
Then double click on mgs2.gp4p and click the Package button.
Save the resultant package in the GameData/package/ folder so that the Vita can access it. Wait about 10 minutes.
Run "*Package Installer" on the Vita, select host0: and then the package. Wait about 30 minutes.
If the package doesn't show up, make sure you are connected to the Vita through the Neighborhood. Try restarting the *Package Installer, opening and closing the directory in windows, and/or rebooting the Vita.
