

リップアニメーションタイムシーケンス(口パク時系列)データフォーマット


※変換ツールが出力するもの


§パケットデータ

	+----------------+ +0x0000
	| パケットヘッダ |
	+----------------+ +0x0010
	|                |
	|                |
	|                |
	|                |
	|  パケット本体  |
	|                |
	|                |
	|                |
	|                |
	+----------------+ +packet_max

	※ packet_max は、デフォルトで 0x0800(2048)。
	   この値はオプションの -p もしくは --packet で変更できる。


§ パケットヘッダ

   パケットヘッダは、以下の構造を持つ(int = 32bit とする)。

    struct {
      int reserved;
      int size;         /* パケット内で有効なデータサイズ(byte単位)     ※1 */
      int start_time;   /* 音声の先頭から、パケット先頭までの時刻       ※2 */
      int flags;        /* 各種フラグ                                   ※3 */
    } packet_header;

    ※1 データサイズは、ヘッダを含めた有効なサイズが収録される。
	--fips(-f)オプションが指定されない限り、この値にかかわらず、
	パケット境界は常に packet_max 単位となる。--fips オプションが
	指定された場合は、パケットサイズはこの値と同じ値になり、可変長
	パケットとなる。
	

    ※2 ヘッダの時刻は、1/300秒単位で収録される。

    ※3 現時点では、

	  0x00000001  最終パケット

	のみがサポートされている。


§ パケット本体

   パケット本体は、以下の構造体の配列として扱われる。

   struct {
     unsigned short time;      /* パケット先頭からの時刻(0xffff = 終端) ※3  */
     unsigned char  phone_id;  /* 音素 ID (0x00 = sil(無音), 0xff = unknown) */
     unsigned char  power;     /* パワー(0〜255)                             */
   } PhoneBlock;

   以上、計4バイト。

   ※3 シーケンス上の時刻は、1/100秒単位で記録される。
       ヘッダに記録されている時刻とは単位が異なるため注意。

   パケット内に収録されているデータの最後には、必ず終端ブロック
   (時刻=0xffff) が付加される。

以上。
