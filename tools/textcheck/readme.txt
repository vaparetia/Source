テキストファイルが EUC/UNIXになっているかどうか判定する。

テキストファイルの改行コードと漢字コードを調べ、
正しくEUC/UNIXになっていないとエラーを表示して、終了する。

改行コードは、

0a   : unix
0d   : mac
0d0a : dos

と判定する。

漢字コードは、

0x1bが出てきたら JIS
( 0x81 <= c1 <= 0x9f || 0xe0 <= c1 <= 0xfc ) && ( 0x40 <= c2 <= 0x7e ) ならShiftJIS
2バイト組で0x80以上ならEUC

と判定。
そのため、ごくまれに判定に失敗する場合もある。

EUC/UNIXのときは、返り値が０、それ以外の時は返り値が１。
（複数ファイルが指定された場合は、そのファイルすべての和になる）

textcheck -v でチェック中のファイル名も表示。
textcheck -q で、ERRORなどの文字列を表示しない（返り値だけ）
