1.0 動作確認環境

  本ドキュメントの対象となるドライバは、以下の環境での動作が確認されている。


	* Linux kernel 2.3.99-pre5
	* Linux kernel 2.3.99-pre6

  Linux kernel 2.3.99-pre7 および pre8 については、USB サポートそのものに
  異常があるらしく、USB 端子に何か一つでも USB デバイスが接続されていれば
  (それが USB Hub であっても) kernel panic を起こすことが確認されている。



  1.1 サポートされるデバイス

    以下の USB デバイスがサポートされている。

	NEC PK-UP010    (AN2720)
        ELECOM UC-NBB   (PL2302)

    同様の Endpoint 構成を持つ同様のデバイスであれば、ソースコード中の
    Vendor / Product ID 候補を追加することで、認識させることが可能と思われる。




2.0 ドライバの組み込み方法


  2.1 ファイル構成

     ドライバは、以下のファイルより構成される。

	linQcable.c
	linQcable.h
	linQcable.diff



  2.2 組み込み手順
      
      以下の作業は Linux kernel のデバイスドライバにかかわる作業であるため、
      ほぼ全般にわたって root 権限において行う必要がある。



    2.2.1 カーネルソースへの編入

	  まず、linQcable.c を、Linux kernel ソースツリーの linux/drivers/usb
	  ディレクトリにコピーする。
	   カーネルのソースが /usr/src/linux 以下に展開されている場合は

	           /usr/src/linux/drivers/usb/

	  以下ということになる。

	  このままではファイルがソースツリー上にあるだけなので、make や config
	  の対象となるように、同ディレクトリの Makefile と Config.in を修正
	  する。

	  修正箇所を説明するのは(同時に修正を手で行うのは)手間がかかるので、
	  手間を省くべく用意したのが linQcable.diff である。同ディレクトリを
	  カレントディレクトリにして、

		  # patch -p0 < ***どこか***/linQcable.diff

	  を実行することで、Makefile, Config.in ともに修正される。

	  また、コンパイルに必要なヘッダファイルである linQcable.h は、
	  このデバイスを使用するアプリケーションを作成する際にも使用される
	  ため、linux/include/linux 以下にコピーする。ソースが /usr/src/linux
	  以下に展開されているなら、

		  /usr/src/linux/include/linux/

	  以下に該当する。

	  以上でソースツリーへの組み込みは終了である。



    2.2.2 config, make

	  普段 kernel を make するときと同様の手順で、kernel の config を
	  行う(make menuconfig もしくは make xconfig がお勧め)。
	  このとき、"USB Support" の項目に

	          "USB LinQ CABLE support"

	  という項目が追加されているはずなので、これを "m" にする(当然のこと
	  ながら、"m" を選択するためには "Loadable module support" 内の
	  "Enable loadable module support" が "y" になっていなければならない)。

	  また、おなじ "USB Support" の項目内にある

		  "Preliminary USB device filesystem"

	  がチェックされていることを確認し、チェックされていなければ
	  チェックする。	  


	  config が終了したら、普段とおなじ要領で kernel を make する。

		 # make clean
		 # make dep
		 # make
		 # make modules

	  のようにして kernel を make し、エラー等なく終了したら make は終了
	  である。ただし、まだブートできる状態にはなっていない。

	  この段階で現在使っている kernel がいつでも起動できるように配慮
	  すべきであるが、その方法等については JF ドキュメント等を参照され
	  たい。

	  下準備が整ったら

		 # make bzlilo
		 # make modules_install

	  として、kernel を lilo からブートできるようにし、kernel modules を
	  インストールする。

	  問題なく再起動されれば kernel の導入は完了である。



    2.2.3 /proc ファイルシステムの準備

	  USB デバイスの状況が確認できるように、/proc filesystem 以下に、
	  USB device file system を mount する。

	  具体的には、mount コマンドを使用して

		  # mount -t usbdevfs none /proc/bus/usb

	  とする。また、毎回これをやるのは面倒であるとおもわれるので、
	  /etc/fstab に 以下の行を追加することをお勧めする。

	  -----------------------------------------------------------
  	  none        /proc/bus/usb      usbdevfs defaults       0 0
	  -----------------------------------------------------------




    2.2.4 デバイスファイルの作成

	  ドライバとアプリケーションの橋渡しをするデバイスファイルを作成する。
	  作成は簡単で、

		# mknod /dev/usblinq0 c 180 66
		# mknod /dev/usblinq1 c 180 67
		# mknod /dev/usblinq2 c 180 68
		# mknod /dev/usblinq3 c 180 69

	  とすれば良い。/dev ディレクトリ以下に、LinQ CABLE 用のデバイス
	  ファイルが作成されている筈である。

	  なお、本ドライバは、Linux kernel に正式に採用されたものではないため、
	  ここで割り当てているデバイスファイルのマイナー番号 66〜69 は、
	  こちらで空きを見付けて無理矢理割り当てたものである(メジャー番号の
	  180 は、USB デバイスほぼ全般に与えられたもの)。
	  以後リリースされる kernel のバージョンによっては、そのまま使用でき
	  なくなる可能性がある。

	  # そうなる前に、オープンソースとして発表し、正式なドライバとして
	  # Linus 氏に組み込んでもらうことを個人的には提案。




3.0 ドライバの使用法

    本ドライバは Linux の kernel module として実装されているため、以下の
    手順をふんでモジュールを組み込まなければ使用できない。

    root 権限において、

		# /sbin/insmod /lib/modules/2.3.99-pre5/usb/linQcable.o

    を実行することで、ドライバが組み込まれる。

		# cat /proc/bus/usb/drivers

    の出力に、

		 66- 81: usb_linQcable

    という行が含まれていれば組み込みは成功である。この状態で USB 端子に
    対象となるデバイスを接続すれば、/dev/usblinq0 〜 /dev/usblinq3 が
    有効になる。

    # 割り当ては、/dev/usblinq0 を始点とし、空いているものからおこなわれる。


以上。
