1.0  使用されるデバイスファイル

     linQcable デバイスドライバを使用したプログラムでは、以下のデバイス
     ファイルを使用する。

	/dev/usblinq0
	/dev/usblinq1
	/dev/usblinq2
	/dev/usblinq3

     これらは、linQcable-HOWTO.txt の 2.2.4 節で作成したデバイスファイルで
     あり、これらのデバイスファイルを用いてアプリケーションの作成を行う。


2.0  デバイスの使用法

     2.1  基本的な入出力


          1.0 節にて挙げたデバイスファイルを読み書きモードでオープンすることで
	  デバイスが使用可能となる。

	  	int fd;

		fd = open("/dev/usblinq0", O_RDWR);

	  本デバイスは入出力の双方を行うデバイスであるため、O_RDWR (読み書き)
	  モードにてオープンされる必要がある。

	  デバイスファイルに対し、読み込みを行うことでデバイスからの入力、
	  書き込みを行うことでデバイスへの出力を行う。

	  	入力:	read(fd, buffer, size);
		出力:	write(fd, buffer, size);

	  デバイスの使用が終了したら、デバイスファイルをクローズする。

		close(fd);

	  以上が入出力の基本である。



     2.2  デバイス情報の取得

	  本デバイスは ioctl システムコールに対応しており、デバイスがどの
	  USB ポートに接続されているかという情報を得ることができる。
	  なお、この ioctl を用いるには、

	      #include <linux/linQcable.h>

	  として、本デバイスに対応したヘッダファイルを読み込んでおく必要が
	  ある。

	      struct lnQ_port_info info;

	      ioctl(fd, LNQ_IOCTL_GETPORT, &info);

	  とすることで、lnQ_port_info 型構造体に、デバイスの接続情報が
	  返される。

	  lnQ_port_info 構造体は、以下の構造を持つ。

	  
		struct lnQ_port_info {
		    int busnum;   /* USB bus           */
	    	    int level;    /* connection level  */
	    	    int parent;   /* Parent HUB device */
	    	    int port;     /* port              */
	    	    int devnum;   /* device number     */
		};

	  busnum は、root hub が接続されている USB バスの番号である。標準的な
	  PC は USB バスを一つしか持っていないと思われるため、通常は 0x01 の
	  値となる。

	  level はUSB接続の階層レベルで、デバイスが USB 接続階層のどのレベルに
	  接続されているかを示す。

	  parent は、デバイスが接続されている USB Hub のデバイス番号である。
	  このデバイス番号は Linux kernel 内部で管理される番号であり、

		$ cat /proc/bus/usb/device

	  としたときに得られるデバイス番号とおなじものである。

	  port は、デバイスが接続されている USB Hub における接続ポートの番号
	  で、最初のポートを 0 番として、接続されているポートに対応する値が
	  返される。例えば 4 つの接続ポートを持つ USB Hub の、2 番目のポート
	  にデバイスが接続されている場合、port の値は 1 となる。
