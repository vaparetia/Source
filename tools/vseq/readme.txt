

口パク時系列テキストデータ バイナリ変換ツール vseq



§ ツールの目的

   vsc による音声分析の結果出力されるデータは、テキスト形式の時系列表であり、
   実際のゲーム用データとして組み込むためには、バイナリ形式に変換したデータで
   あることが望まれる。

   vseq は、vsc の出力結果のテキストファイルを、組み込み可能なバイナリデータに
   変換するためのものである。

   実際の使用に最しては、ストリーミングが必要な場合において、vstream による
   さらなる加工が必要になる。



§ 出力データ

   出力されるデータは、以下の形式をもつ。

   struct voice_sequence {
     unsigned short time;      /* 音声先頭からの時刻 ※2 */
     unsigned char  phone_id;  /* 音素 ID            ※1 */
     unsigned char  power;     /* パワー                 */
   }

   ※1 音声先頭からの時刻

       時刻が 0xffff の場合、時系列データの終端を表す。


   ※2 音素 ID

       音素IDは、「どの言語で」話された音声を分析したかによって、
       コードブックが異なる。具体的な例では、英語と日本語では音素記号の
       体系が異なる。処理の都合上、テキストで書かれた音素記号を音素ID という
       数値に変換しなければならないため、どの音韻記号で書かれているかを
       オプションで指定する必要がある。
