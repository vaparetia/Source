■makexti4よりの修正点

	・xboxの圧縮形式であるDXTnファイルを作成できるようになりました。
	・重なり判定の関数を高速化。


■使い方
	

	◆前準備
		このツールは XDxtex.exe と combine.exe を外部コマンドとして呼び出しているので
		使用するときはパスのとおっている場所にこれらのファイルを置いてください。
		(￥toolx\binの中においています。）
	

	◆入力のしかた
	
	makexti5 -o [OutputFileName] -i [InputFileName] -d -c [DXT1|DXT2|DXT3|DXT4|DXT5]
	
	-o 出力名
	-i 入力ファイル名。ワイルドカード使用可。
	-d -dでDDSファイル形式で出力。
	-c 圧縮形式。このオプションのあとに[DXT1|DXT2|DXT3|DXT4|DXT5]から
		圧縮形式を選択してください。
	

	
	例:
	>makexti5 -o w00a -i *.bmp -d -c DXT2
		
	カレントディレクトリにある bmpファイルをすべて読み込み、
	DXT2形式に圧縮された XTIファイルが出力されます。

			↓
	
	出力ファイル
		w00a.xti		XTIファイル
		w00a.dds		圧縮前のDDSファイル
		w00aDXT2.dds	圧縮後のDDSファイル
		w00a.~bmp~		BMPファイル。
