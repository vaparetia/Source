----------------------------------------------------------------------------	
	サムネイル用画像縮小プログラム    thumbnail

2001/5/1       Yuko Yano
----------------------------------------------------------------------------

thumbnail [引数1] [引数2] [引数3] [引数4]


戻り値------縮小後のサイズ

引数1 ------縮小するraw画像ファイル名
引数2 ------縮小前の横の長さ
引数3 ------縮小前の縦の長さ
引数4 ------縮小後のファイル名

trans.cの#defineで、BLEND と SENKEI で縮小方法を選べるようになってい
ます。
BLEND が周辺画素の平均値で求める方法(高縮小のときおすすめ)
SENKEI が線形補完法。(1/2より縮小率が高い時おすすめ)

 縮小後のサイズは main関数があるファイル(thumbnail.c または  ps2thumb.c)の
define文のところで任意に変えられる。
 また、PS2版は、縮小後にテレビ画面に縮小した画像が表示されるようになっ
 ている。
     
注)
現在、画面の初期化のため zero[448][512*4] の大きさの配列をとって、
0で初期化し、initLoadImage に吐いている。
