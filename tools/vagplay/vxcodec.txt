MetroWerks 社製 Macintosh 向け開発環境 CodeWarrior (CW11) のライブ
ラリ形式

● エンコードルーチンの流れ

エンコードは、16 bit データの 28 サンプル分 (56 バイト) を  1 ブロック単位と
して行います。ループ情報は、VAG ヘッダではなく、波形データ自体に付加されます。

エンコードに際しては次頁関数群を使用し、下記の手順で行います。

(1) EncVagInit() にてモードを指定し、エンコードルーチンを初期化する。
(2) 28 サンプル単位で EncVag() をコールし、圧縮変換を行う。
(3) (2) を繰り返す。
(4) 最後のブロックを 0 パディングし、EncVag() をコールする。
(*) one shot 波形の場合は、EncVagFin() をコールする。

● VAG ファイル

本エンコーダルーチンでは、VAG ヘッダなどの出力はしません。VAG ファイルとして出
力する際は、 'VAGp' もしくは 'pGAV' で始まる 30H の VAG ヘッダ、16 バイトの波
形開始ブロック(中身は全て 0 )に引き続き、EncVag() の出力データを付加してくださ
い。さらに、one shot 波形の際には、EncVagFin() で得られる波形終了ブロックを最後
に加える必要があります。

VAG ヘッダ ('VAGp'・・・)
30H (48 バイト)

波形開始ブロック(all 0)
10H (16バイト)

波形データ
任意

波形終了ブロック(one shot の場合のみ)
10H (16バイト)


波形終了ブロックを省略すると、SPU 割込みが誤動作することがあります。ループあり波
形の場合は、波形終了ブロックを付加する必要はありません。

● 関数仕様
____________________________________________________________
void EncVagInit ( short conv_mode )

エンコードルーチンの初期化およびVAGを行います。波形データをエンコードす
る際、はじめに必ず一度コールする必要があります。

変換モード conv_mode を、"Stndard"、"High Band"、"Low Band"、"4bit 
Straight" の中から指定します。

1: Standard
2: High Band (高周波成分を多く含む波形に有効)
3: Low Band (定収は成分を多く含む波形に有効)
4: 4bit Straight (16 bit を 4 bit に直線変換)

____________________________________________________________
void EncVag ( short x[], short y[] , short block_attribute )

配列 x で指定された 28 サンプル分 (56バイト) のデータを圧縮変換し、16 
バイトの 配列 y にストアします。配列 y は、8 short wordで構成されます。

この際、ループの設定を block_attribute にて下記の通り指定します。

0 : ループ無し波形 (one shot)
1 : ループ無し波形かつ波形終了ブロック
2 : ループ有り波形かつループ開始ブロック
3 : ループ有り波形 (非開始、非終了ブロック)
4 : ループ有り波形かつ波形終了ブロック

____________________________________________________________
void EncVagFin ( short y[] )

SE などの one shot (非ループ) 波形を圧縮変換した際は、最後にこの関数を呼ん
で波形終了ブロックを負荷する必要があります。配列 y は、8 short word で構
成されます。

・XA ENCODER

	まだ試作段階ですがVAG ENCODERを改造して作成したXA ENCODERを用意しました。

	________________________________________________________________________
	void EncXaInit(void)

	エンコードルーチンを初期化します。パラメータの指定はありません。

	________________________________________________________________________
	EncXa(WORD *x, UBYTE *y, UBYTE fn, UBYTE ch, UBYTE sm, UBYTE ci)

	1セクタ(28サンプル×8ユニット×18サウンドグループ)の
	16bit linear PCM を変換します。ファイル番号をfnに、チャンネルをchに、
	サブモード(通常は0x64)をsmに、コーディング情報をciに指定します。

	ステレオデータの場合はあらかじめ、1ユニット毎に左右の
	チャンネルデータを配置しておく必要があります(暫定)。
	1グループ内は左チャンネル、右チャンネルの順に4ユニットづつ
	計8ユニットから構成されます。。

・VAG DECODER

	________________________________________________________________________
	LONG decodeVAG(UBYTE *s, WORD *d, LONG p_len)

	sからp_lenブロック分のVAGデータを16bit linear PCM に変換し
	dに格納します。返り値は実際に変換されたバイト数です。

	________________________________________________________________________
	LONG decodeVAGf(UBYTE *s, WORD *d, LONG p_len)

	decodeVAG関数の実数演算版です。


・XA DECODER

	________________________________________________________________________
	LONG decodeXA(UBYTE *s, WORD *d, LONG s_len)

	sからs_lenセクタ分のXAデータを16bit linear PCM に変換し
	dに格納します。返り値は実際に変換されたバイト数です。

	________________________________________________________________________
	LONG decodeXAf(UBYTE *s, WORD *d, LONG s_len)

	decodeXA関数の実数演算版です。


・注意点

	エンコードの際に符号付き16bitを-32768～+32767から
	-30720～+30720の範囲に強制的に切り捨てています。
	元波形をノーマライズする場合には93.75%以下にしないと
	それを超える部分がクリップしてしまいます。
	正弦波などの単純波形や低周波成分などは要注意です。

	ステレオデータを変換する場合はデコード・エンコード環境を
	左右それぞれ独立して保持する必要があります。
	XAの場合は内部で左右独立で処理していますが
	複数のチャンネルを並列にエンコード・デコードすることはできません。
