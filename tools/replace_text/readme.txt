//
// 日本語文字列置き換えツール replace_text.pl について
//

実験的に組んだものなので、まだ汎用性を持たせるにいたっていません。

このツールはテキストファイルにある日本語文字列を置き換えるツールです。
テキストファイル中にある""でくくられた日本語文字列を置き換えます。

＜使用言語＞
　このツールはPerlを使用しています。

＜使用方法＞
　replace_text.pl <拡張子>

　引数として拡張子を指定します。
　実行されたディレクトリ以下にあるファイルで、指定の引数の拡張を持つファイルを検索対象とします。

　日本語置き換え用のリストファイルを読み込み、発見したファイル内に置き換えるべき日本語を発見するとリストファイルを元に置き換えます。
　置き換え用のリストファイルの参照先は、replace_text.pl内に直書きです。必要に応じて書き換えてください。

＜注意＞
　このツールはjcode.plをインクルードしています。

＜関連＞
　置き換え用のリストファイルを作成するツールはget_text.plです。
　get_text.plが出力するファイルは、replace_text.plによって置き換えられることを想定しています。
