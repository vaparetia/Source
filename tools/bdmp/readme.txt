

ファイルダンプユーティリティ bdmp


§ 概要

   既に同様のものがあるようですが、ファイルダンプユーティリティです。
   以下の特色があります。

	* 領域指定ダンプが可能
	  ファイル内の特定のアドレス領域のみをダンプさせることができます。

	* BYTE / WORD / LONG ダンプ
	  表示を 8bit, 16bit, 32bit の3種から選択可能です。

	  ※ WORD / LONG 時の値は、必ず 2byte / 4byte 境界より取得されます。
	     領域指定と組み合わせた場合は、領域のほうがそれぞれの境界に補正
	     されます。

	* エンディアン切替え
	  WORD / LONG 表示の際、値のとり方をビッグエンディアン、
	  リトルエンディアンのいずれかより選択可能です。


    長大なファイルの、途中一部のみのダンプが欲しい場合に利用価値があると
    思われます。


§ オプションの説明


   -a begin-term	開始、終了アドレス指定
   -a begin[-]		開始アドレスから、ファイル終端まで
   -a -term		ファイル始端から、終了アドレスまで

	ダンプ領域を指定します。begin, term はいずれも16進数列で指定します。

	注) 先頭に "0x" は付けないでください。



   -w			WORD モード

	ダンプの出力を、WORD(16bit) 表示にします。デフォルトでは、ファイル内の
	値をリトルエンディアン(L->H)で解釈しますが、これはオプションで変更する
	ことができます。値の取得は、必ず2バイト境界(第0bit が 0 になっている
	アドレス)から行われます。

	領域指定で先頭もしくは終端に奇数アドレスが指定されている場合は、指定
	された領域を完全に含みうる、2バイト境界で区切られた最小の領域を出力
	します。



   -l			LONG モード

	ダンプの出力を、LONG(32bit) 表示にします。デフォルトでは、ファイル内の
	値をリトルエンディアン(L->H)で解釈しますが、これはオプションで変更する
	ことができます。値の取得は、必ず4バイト境界(下位2bit が 00 になっている
	アドレス)から行われます。

	領域指定で先頭もしくは終端に指定されたアドレスが 4バイト境界の途中に
	ある場合は、指定された領域を完全に含みうる、4バイト境界で区切られた
	最小の領域を出力します。


   ※ -w, -l のいずれも指定されていない場合は、BYTE(8bit)モードでの出力と
      なります。


   -little		リトルエンディアンモード

	WORD / LONG モードにおける値の解釈を、リトルエンディアン(L->H)で
	行うよう指示します。デフォルトなので、指定しなくても構いません。


   -big			ビッグエンディアンモード

	WORD / LONG モードにおける値の解釈を、ビッグエンディアン(H->L) で
	行うよう指示します。ビッグエンディアン環境で使用するデータを出力する
	際に重宝するかもしれません。


以上です。
