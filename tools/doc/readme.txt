<1999/05/31>
  Operation KMD tool ;

  このツールは、kmdファイルを表示、又は 変換するツールです。
kmdファイルを順に変化させていき、kmdrファイル形式にデータを変えていきます。



( 使用方法 )
･ kmdファイル内のデータ表示 
    ope_kmd -print <ファイル名>  <出力先ファイル名>
    
･ kmdファイル内に拡張モデルが存在している場合、親モデルと統合する。
    ope_kmd -union <ファイル名>  <出力先ファイル名>

･ kmdファイル内のポリゴンを全て三角形に分解する
    ope_kmd -divide <ファイル名> <出力先ファイル名>

･ 三角形に分解したkmdファイル内のデータをkmdrファイルに変換する 
    ope_kmd -strip <ファイル名> <出力先ファイル名>

( kmd → kmdr への変換 )
a.kmd ファイルが存在するとする。

   ope_kmd -union a.kmd  b.kmd

上記のコマンドにより、a.kmd ファイル内に拡張モデルが存在した場合、拡張モデルと
その拡張元のモデルを一つのモデルに統合する。

   ope_kmd -divide b.kmd c.kmd

上記のコマンドにより、b.kmd ファイル内のプリミティブをすべて三角形の形に分割する。

   ope_kmd -strip c.kmd  d.kmdr

上記のコマンドにより、c.kmdファイルをkmdrデータ形式に変化させる。
