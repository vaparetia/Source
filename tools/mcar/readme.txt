 このファイルは mcget, mcput, mcar の3つのツールのドキュメントファイルです。
 このツールのいづれも、メモリーカードスロットの"1"にしか対応していません。
 また、PS2のメモリーカードであることを前提にしています。
 PS1メモリーカードやPockertStationでは動作の保証はありません。

---------------------------------------------------------------------------
/* mcget */

mcget [出力ファイル名]
(ファイル名がない場合は、"mcdata"に標準出力されます。)

<説明>
 PS2上で動くプログラムです。
 PS2のメモリーカードの内容すべてを1ファイルにして、ローカル(host0:)の
ハードディスクに保存します。

<出力ファイル構造>
**メモリーカード上**        **ローカル上**
DirAAA -+- FileA             DirAAA
        +- FileB             FileA
        +- FileC             FileB
                             FileC
DirBBB -+- FileD             DirBBB
        +- FileE             FileD
        +- FileF             FileE
                             FileF
DirCCC -+- FileG             DirCCC
        +- FileH             FileG
      .                        .
      .                        .
      .                        .
 このように出力ファイルでは、ディレクトリの中のファイルはディレクトリファイルの
すぐ下に単純に書き込まれていきます。
 一応、このプログラムではディレクトリの中にさらにディレクトリがあっても
大丈夫な構造になっていますが、PS2の規約で「サブディレクトリの下にはディレクトリを
作ってはいけない」ことになっています、、、

 ひとつひとつのファイルの構造は以下の通りです。
*****ディレクトリファイル*****
 1バイト ...ファイルパスの文字列の長さ
？バイト ...ファイルパスの文字列
64バイト ...情報ファイル(データファイルのサイズ、属性、更新日時など)
*****ファイル*****************
 1バイト ...ファイルパスの文字列の長さ
？バイト ...ファイルパスの文字列
64バイト ...情報ファイル(データファイルのサイズ、属性、更新日時など)
？バイト ...データファイル(実体)

<情報ファイル内約>
 sceライブラリのsceMcTblGetDir構造体の形でデータが入っています。
*****sceMcTblGetDir構造体**********
typedef struct {
             struct {
                     unsigned char Resv2,Sec,Min,Hour;
                     unsigned char Day,Month;
                     unsigned short Year;
             } _Create;
             struct {
                     unsigned char Resv2,Sec,Min,Hour;
                     unsigned char Day,Month;
                     unsigned short Year;
             } _Modify;
             unsigned FileSizeByte;
             unsigned short AttrFile;
             unsigned short Reserve1;
             unsigned Reserve2;
             unsigned PdaAplNo;
             unsigned char EntryName[32];
} sceMcTblGetDir ;

---------------------------------------------------------------------------

/* mcput */

mcput <入力ファイル名>

<説明>
 PS2で動くプログラムです。
 上記の mcget で出力したファイルを再びPS2メモリーカードにデータを吐き出す
プログラムです。
 一度メモリーカードをフォーマットするので以前のデータは消えます。
注意して下さい。

---------------------------------------------------------------------------

/* mcar */

mcar [コマンド] <入力ファイル名>
	コマンド--->	-t	ディレクトリとタイトル名のみ表示(デフォルト)
			-tv	全ファイルとタイトル名を表示

<説明>
 UNIX上で動くプログラムです。
 上記の mcget にてローカルにとってきたメモリーカードのデータの中の一覧を
表示するプログラムです。
